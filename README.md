# 🤖 Loopa Telegram Bot

A Telegram bot that converts new audiences into channel members by requiring users to join **[@loopahub](https://t.me/loopahub)** before they can use the bot.

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new)

---

## 📋 Features

- ✅ **Force Join / Verification** — Users must join `@loopahub` before using the bot.
- ✅ **Inline Buttons** — Clean "Join Channel" and "Check Verification" buttons.
- ✅ **Long Polling** — No webhook or public domain required.
- ✅ **Railway Ready** — Deploys in minutes with a `Procfile`.
- ✅ **Environment Variables** — Token stored securely, never in code.
